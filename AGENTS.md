- In Rust-versus-Luau speed proofs, keep the source plugin algorithm, API call order, fixtures, and output identical. Only gains from generated Luau, bridge, or runtime work count as proof.
- For compiler changes, fail closed with `file:line:column` when exact Luau semantics are unproven. Test nullness, integer width and signedness, binding identity, evaluation order, strict ABI markers, and generated-script parse. For each semantic fix, the regression test must fail on the pre-fix head.
- For corpus parity claims, re-record md5, scan, and parse baselines when the compared SHA changes. Never reuse a baseline labelled with a different SHA.

## Strict compatibility research

- With Noctalia API 57 frozen, strict can only run code expressible as Luau plus API 57 members. Arbitrary Rust, FFI, raw pointers, threads, blocking IO, sockets, and native-effect crates or crates with unmappable effects cannot run without a helper or a host change. Auto and off remain the modes for that code.
- The 366 plugin handler crates have direct runtime dependencies only on `noctalia-rs`, `serde`, and `serde_json`, plus `noctalia-rs-build` as a build dependency. The only non-API 57 host calls found are `noctalia.sound.getVolume`, `noctalia.setTimeout`, `barWidget.setActive`, and the internal `__noctalia_rs.httpStreamStop`. A strict-first noctalia-rs API can replace them with a typed volume read over `getSetting` or `getConfig`, timers built on `setUpdateInterval` or `set_interval`, colors, and stream handles.
- Unmodified corpus source has a source and API residual set of about 72 entries: JSON null in containers, `Context::Parts` and `set_op_sink`, coroutine and thread-local scheduling, raw context pointers, callbacks with no behavior branch, and the legacy host calls. Compiler-only work should target about 995 of 1,067 strict entries. Reaching 1,067 of 1,067 needs plugin rewrites under a strict-first API.
- A strict-first noctalia-rs API should remove `Context::Parts`, `set_op_sink`, coroutine helpers, raw pointers, and null-valued container slots. It should expose typed events, callback handles for async work, timers, state watches, and an explicit `Option`-based JSON model where `None` omits object keys and is disallowed in array slots. Emit helper functions as local Luau functions inside the one generated entry script. No user-authored helper Luau file is needed.
- Performance claims compare strict generated Luau with hand-written Luau on API 57 and with the auto helper path. Strict removes helper IPC. It does not make native-only Rust run faster or possible.
